Plugin de seguridad todo en uno para WordPress. Antivirus con seis modos de escaneo, cortafuegos, verificación en dos pasos, límite de intentos de acceso, comprobación de integridad y copias de seguridad.

`PHP` · `WordPress` · `Seguridad web`

### ServerGuard

Anticheat para Minecraft 1.21.1. Detección de movimiento irregular y validación en el lado del servidor, sin confiar en el cliente.

`Java` · `Detección de anomalías`

**[Ver el repositorio](https://github.com/Maitini/ServerGuard)**

</td>
